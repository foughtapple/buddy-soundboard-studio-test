## Starting requirements

Create a polished Windows desktop mini soundboard studio for testing AI Code Buddy.

Requirements:
- Build a Python Windows desktop app with a clean GUI.
- The app should act like a small soundboard / sample pad.
- Show a title at the top: “Soundboard Studio”.
- Display 8 large sound pad buttons in a 2 x 4 grid.
- Each pad should have a name, such as Airhorn, Applause, Laser, Drum Hit, Bell, Error Buzz, Magic, and Victory.
- When I click a pad, play a short generated sound effect using standard Python/Windows capabilities where practical.
- Do not require external audio files for the first version.
- Show a visual “Now playing” label when a pad is pressed.
- Add a volume slider.
- Add a Stop Sound button if practical.
- Add a simple activity log showing the last 10 played pads.
- Use a polished dark theme with clear buttons.
- Keep the project minimal but impressive.
- Store no private data.
- Include a README with setup, run, test, and package instructions.
- Include basic tests for any non-GUI sound/log helper functions.
